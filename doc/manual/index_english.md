# ComfyUIRunWorkflow User Manual

✨ [日本語](index.md)

This manual explains how to use ComfyUIRunWorkflow in plain language, without assuming any programming knowledge.
(For detailed technical documentation aimed at developers, see [doc/usage.md](../usage_english.md).)

## What This App Does

ComfyUIRunWorkflow lets you use "ComfyUI" — a powerful but complex image-generation tool — through a simple screen, without touching any complicated settings.
Just pick a pre-made "workflow" (think of it as an art style) and describe what you want (a prompt), then click Run to generate an image.

## Before You Start

- To use this app, a separate program called "ComfyUI" must already be running on the computer. If it isn't set up yet, ask whoever provided you with this app (your administrator).
- Keep the app (`ComfyUIRunWorkflow.exe`) together with the other files it was distributed with, such as `workflow_config.json`. Moving or deleting files from that folder may prevent the app from working correctly.

## Page Guides

| Page | What you can do |
|---|---|
| [Settings](settings_english.md) | Initial connection and save-location setup |
| [Home](home_english.md) | Generate one image (or several at once) |
| [Queue](queue_english.md) | Automatically generate several different images in a row |
| [Generate](generate_english.md) | Bulk-create a large number of generation jobs that only differ by character or outfit |
| [Data](data_english.md) | Review generated images and tagging results |
| [Tagger](tagger_english.md) | Automatically extract descriptive tags from an image |
| [Config](config_english.md) (for administrators) | Change workflow and LoRA settings from the screen instead of editing a file directly |

If this is your first time, we recommend reading [Settings](settings_english.md) followed by [Home](home_english.md).

## About the Icons on the Left

Click the icons along the left edge of the app to move between pages. The gear icon at the bottom opens the Settings page.

## If Something Goes Wrong

- If an error message appears, check the notification (a small popup) that shows in the corner of the screen.
- If you can't resolve it, share the exact error message with whoever set up the app for you (your administrator).
