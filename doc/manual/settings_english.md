# Settings Page

✨ [日本語](settings.md)

Open this page first, before using the app, to configure a few basic items.

![Settings page](../images/settings_page_en.png)

## What to Set Up

| Item | Description |
|---|---|
| Theme | Choose a light or dark color scheme for the app, whichever you prefer |
| Language | Switch the display language between "日本語" and "English" — the change applies to the whole app immediately |
| ComfyUI URL | The location of "ComfyUI", the program that actually generates images. You normally won't need to change this (ask your administrator if you're not sure) |
| workflow_config.json Path | The location of the file that defines the available art styles. You normally won't need to change this |
| Results Output Folder | Where generated images and results are saved |

Click the folder icon next to each field to open a file or folder picker.

## Good to Know

- Your settings are saved automatically and carried over the next time you open the app.
- The "ComfyUI URL" and "workflow_config.json Path" are usually set up once by your administrator, so you shouldn't normally need to touch them.
