# Home ページ（画像を生成する）

✨ [English](home_english.md)

このページでは、1枚の画像（または同じ内容で複数枚）を生成できます。まずはこのページから使ってみましょう。

![Home ページ](../images/dashboard_page.png)

## 手順

1. 画面上部の **ワークフロー** から、生成したい絵のスタイルを選びます（例: `anima`、`sdxl` など）。どんな種類があるかは、あらかじめ用意されている内容によって異なります。
2. **ポジティブプロンプト** の欄に、描いてほしい内容を英単語やフレーズをカンマ（,）区切りで入力します（例: `1girl, blue hair, smile`）。
3. **ネガティブプロンプト** の欄に、描いてほしくない内容を同じように入力します（すでに入力されている内容はそのままで問題ありません）。
4. **画像サイズ** で、縦長・横長・正方形などから選びます。
5. 必要であれば **LoRA**（追加の絵柄・演出を加える上級者向け機能）を追加します。分からなければそのままで構いません。
6. 必要であれば **ファイル名プレフィックス** に、保存される画像ファイル名の先頭に付けたい文字を入力します。空欄のままでも問題ありません。
7. 一度に何枚生成するかを **バッチ数** で指定します（1〜10）。
8. 左下の **実行** ボタンをクリックします。

## 生成中・生成後

- 実行中は画面下部にバーが表示され、進み具合が確認できます。
- 生成が終わると、右側に画像のサムネイル（縮小版）が表示されます。クリックすると大きく表示されます。
- うまくいかなかった場合は、画面の隅に赤い通知（エラーメッセージ）が表示されます。内容を確認し、必要であれば管理者に相談してください。

## 設定を保存・呼び出す（インポート・エクスポート）

画面右上の **エクスポート** ボタンを押すと、今入力している内容（ワークフロー・プロンプト・画像サイズなど）をファイルとして保存できます。
保存したファイルは、**インポート** ボタンから読み込んで、同じ内容を再現できます。同じような画像を何度も生成する場合に便利です。
