# ComfyUIRunWorkflow 操作マニュアル

✨ [English](index_english.md)

このマニュアルは、プログラミングの知識がない方でも ComfyUIRunWorkflow を使えるように、画面の操作方法を分かりやすくまとめたものです。
（開発者向けの詳しい技術資料は [doc/usage.md](../usage.md) を参照してください）

## このアプリでできること

ComfyUIRunWorkflow は、「ComfyUI」という画像生成の仕組みを、難しい設定画面を触らずに簡単な操作で使えるようにするアプリです。
あらかじめ用意された「ワークフロー」（絵のスタイルのようなもの）と、描いてほしい内容（プロンプト）を選んで実行ボタンを押すだけで、画像が生成されます。

## 使い始める前に

- このアプリを使うには、あらかじめ「ComfyUI」という画像生成用のプログラムが別途パソコン上で起動している必要があります。ComfyUI が用意されていない場合は、環境を用意してくれた方（管理者）に確認してください。
- アプリ本体（`ComfyUIRunWorkflow.exe`）と、あわせて配布されている `workflow_config.json` などのファイルは、フォルダごとまとめて保管してください。中のファイルを移動・削除すると正しく動かなくなることがあります。

## 各ページの使い方

| ページ | できること |
|---|---|
| [設定ページ](settings.md) | 最初に行う接続設定・保存先の設定 |
| [Home ページ](home.md) | 画像を1枚（またはまとめて数枚）生成する |
| [Queue ページ](queue.md) | 内容の異なる画像を複数まとめて自動生成する |
| [Generate ページ](generate.md) | キャラクターや衣装だけ変えた大量の生成予約を一気に作る |
| [Data ページ](data.md) | 生成した画像や、タグ付けした結果を見返す |
| [Tagger ページ](tagger.md) | 画像に写っているものを説明する単語（タグ）を自動で取り出す |
| [Config ページ](config.md)（管理者向け） | ワークフローや LoRA の設定を、ファイルを直接編集せずに画面から変更する |

初めて使う場合は、[設定ページ](settings.md) → [Home ページ](home.md) の順に読むのがおすすめです。

## 画面左のアイコンについて

アプリの左端に並んでいるアイコンをクリックすると、それぞれのページに移動できます。一番下の歯車アイコンが設定ページです。

## 困ったときは

- エラーメッセージが表示された場合は、画面の隅に出る通知（吹き出し）の内容を確認してください。
- 解決しない場合は、アプリを用意した方（管理者）に、表示されたエラーメッセージの内容をそのまま伝えてください。
