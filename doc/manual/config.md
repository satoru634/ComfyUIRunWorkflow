# Config ページ（ワークフロー設定の編集）（管理者向け）

✨ [English](config_english.md)

`workflow_config.json` という、絵のスタイル（ワークフロー）や LoRA の設定が書かれたファイルを、テキストエディタを使わずにアプリの画面から編集できるページです。
このページは主に、アプリをセットアップする管理者の方向けの機能です。ふだん画像を生成するだけであれば、このページを触る必要はありません。

## 基本の使い方

1. 画面上部の「comfyui_url」「default_workflow」などの共通設定を必要に応じて確認・変更します
2. 画面左のワークフロー一覧から、編集したいワークフローを選びます
3. 右側に表示される画像サイズ・LoRA の項目を編集します
4. 編集が終わったら、画面右上の **保存** ボタンをクリックします

保存を押さずに他のページへ移動すると、編集した内容は失われます。編集したら必ず保存してください。

## ワークフローの追加・削除

- 左上の **＋ ワークフローを追加** をクリックすると、新しいワークフローが追加され、その場で名前を入力できる状態になります
- ワークフロー名は一覧の項目をダブルクリックすることでいつでも変更できます
- 削除したいワークフローの右にある **×** ボタンをクリックすると削除できます。ただし「default_workflow」に指定されているワークフローは削除できません

## 画像サイズの編集

「画像サイズ」欄の左端にある種類選択（default／vertical／horizontal／square）で編集したい種類を選ぶと、その種類の幅・高さが右側の2つの欄に表示されます。数値を変更してから別の種類に切り替えると、変更内容はその種類のものとして保存されます。4種類とも同じ欄で順番に編集します。

## LoRA の編集

選んだワークフローの右側の「LoRA」欄で、LoRA 1件につき「論理名」「ファイル名」「強度（strength）」の3つを入力します。**+ LoRA を追加** で行を増やし、行の左端の **×** ボタンで削除できます。

**+ LoRA を追加** の隣にある2つの並び替えボタンをクリックすると、一覧を LoRA名（論理名）の五十音・アルファベット順で昇順・降順に並び替えられます。LoRA の数が多くなってきたときに、目的の LoRA を探しやすくするための機能です。

## 保存時の確認について

保存ボタンを押すと、内容に誤りがないか自動でチェックされます。画像サイズの数値がおかしい場合や、LoRA の論理名が空欄・重複している場合などはエラーが表示され、保存は行われません。表示されたエラー内容を確認して、入力を直してから再度保存してください。

新しく追加したワークフローに対応する画像生成用のテンプレートファイルがまだ用意されていない場合、保存自体はできますが、その旨の注意メッセージが表示されます。実際にそのワークフローで画像を生成する前に、テンプレートファイルの準備を管理者に確認してください。

## 補足

- 「wd14_tagger」欄のモデル名はドロップダウンから5種類の候補（wd-vit-tagger-v3 など）の中から選びます
- 「wd14_tagger」欄のモデル名を空欄にして保存すると、タグ付け機能（[Tagger ページ](tagger.md)）の設定自体が無効になります
- 「prepend_tags」「exclude_tags」は、カンマ区切りで複数のタグを入力できます
