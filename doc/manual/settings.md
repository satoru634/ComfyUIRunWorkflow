# 設定ページ

✨ [English](settings_english.md)

アプリを使い始める前に、最初に開いて設定する項目をまとめたページです。

![設定ページ](../images/settings_page.png)

## 設定する項目

| 項目 | 説明 |
|---|---|
| テーマ | 画面の見た目を明るい配色（Light）・暗い配色（Dark）から選べます。お好みで選択してください |
| 言語 | 画面の表示言語を「日本語」「English」から選べます。切り替えるとすぐに画面全体へ反映されます |
| ComfyUI URL | 画像生成を行うプログラム「ComfyUI」の場所を指定します。通常は変更する必要はありません（分からない場合は管理者に確認してください） |
| workflow_config.json パス | 絵のスタイルなどの設定が書かれたファイルの場所を指定します。通常は変更する必要はありません |
| 結果出力フォルダ | 生成した画像や結果を保存するフォルダを指定します |

それぞれの項目の右側にあるフォルダのアイコンをクリックすると、ファイルやフォルダを選ぶ画面が開きます。

## 補足

- 設定した内容は自動的に保存され、次回アプリを開いたときも引き継がれます。
- 「ComfyUI URL」や「workflow_config.json パス」は、通常は最初に管理者が設定してくれるため、基本的には触る必要はありません。
