# Tagger ページ（画像からタグを取り出す）

✨ [English](tagger_english.md)

画像を1枚選ぶと、その画像に写っているものを表す単語（タグ）を自動で取り出してくれるページです。

![Tagger ページ](../images/tagger_page.png)

## 手順

1. **画像を選択** ボタンをクリックするか、画像ファイルを画面にドラッグ＆ドロップして選びます。
2. 選んだ画像がプレビュー表示されます。
3. **タグ付け実行** ボタンをクリックします。
4. しばらくすると、右側にタグ（カンマ区切りの単語）が表示されます。
5. **コピー** ボタンをクリックすると、タグの文字列をクリップボードにコピーできます。他のアプリに貼り付けて使えます。

## 補足

- タグ付けに使われる細かい設定（精度など）は、あらかじめ管理者が設定したものが使われます。ページ上で変更することはできません。
- タグ付けした結果は自動で保存され、[Data ページ](data.md) の「タグ付け履歴」タブからいつでも見返せます。
